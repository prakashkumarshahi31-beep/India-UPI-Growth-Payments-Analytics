# India-UPI-Growth-Payments-Analytics
Data analytics project exploring India's UPI payment growth using MySQL, data cleaning, and make interactive dashboard using Power bi.


## 📌 Project Overview

This project analyzes the growth of India's Unified Payments Interface (UPI) using monthly payment data. The goal is to understand digital payment adoption, transaction volume, transaction value, average transaction value, and bank participation over time.

The project uses SQL for data analysis, a cleaned dataset for analytical work, and an interactive dashboard to visualize important trends and business insights.

## 🎯 Project Objectives

- Analyze monthly UPI transaction volume and value.
- Track UPI growth over time.
- Examine the number of banks live on UPI.
- Analyze average transaction value.
- Compare month-over-month growth in transaction volume and value.
- Identify important trends and insights from the data.
- Check the dataset for missing values and duplicate records.

## 🛠️ Tools & Technologies

- **MySQL** — SQL queries and data analysis
- **CSV** — Dataset storage
- **Data Cleaning** — Missing-value and data-quality checks
- **Interactive Dashboard** — Data visualization
- **GitHub** — Project documentation and version control
